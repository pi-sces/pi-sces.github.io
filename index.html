Quick start

From SD card to running appliance in four steps.

# flash, then join the AP and open the web app
xz -d Pi-sces.img.xz
sudo dd if=Pi-sces.img of=/dev/sdX bs=4M status=progress conv=fsync
# join WiFi "P4wnP1" → browse to http://172.24.0.1:8000
